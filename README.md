# MedicalOfficeManagement - Sistema de Gestión para Consultorio

## Descripción

MedicalOfficeManagement es un sistema de escritorio desarrollado en C# para la gestión de las operaciones de un consultorio médico.

El sistema permite administrar la información de los pacientes, gestionar y programar citas médicas, llevar el control financiero del consultorio y gestionar el acceso de los usuarios mediante autenticación.

El proyecto se encuentra en desarrollo y tiene como objetivo aplicar y fortalecer conocimientos en desarrollo de aplicaciones de escritorio, manejo de bases de datos y desarrollo de software.

## Funcionalidades

- **Gestión de pacientes:** Registro, consulta, actualización y eliminación de pacientes.
- **Agenda de citas:** Programación y gestión de citas médicas.
- **Gestión financiera:** Registro y control de ingresos y egresos del consultorio.
- **Autenticación de usuarios:** Inicio de sesión y control de acceso al sistema.

## Tecnologías

- **Lenguaje:** C#
- **Framework:** .NET Framework
- **Interfaz:** Windows Forms
- **Base de datos:** SQL Server
- **Componentes UI:** Infragistics
